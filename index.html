Local Finance Parser

A personal bookkeeping utility operated by the owner of the GitHub account traviswei1325-ops. It is being configured to run on the owner's Mac, read authorized Gmail finance messages, and use a local AI model to extract structured bookkeeping records.

How it works

The local program is designed to send formatted results back to the same authorized Gmail account. The owner's existing Google Apps Script then imports those messages into Google Sheets.

Google account access

The application requests permission to read Gmail messages and attachments and to send the formatted results. It does not request permission to delete messages. Google sign-in takes place through Google's authorization page, not on this website.

This is a private, single-owner workflow, not a public sign-up service. This website only provides application information; it does not receive finance emails or Google access tokens.
